# Challenge title

Put the original writeup text here.

No frontmatter is required. The first level-one heading becomes the post title.

To group posts by category, save the file in a category folder, for example:

```text
content/writeups/reverse/challenge-name.md
content/writeups/pwn/challenge-name.md
content/writeups/crypto/challenge-name.md
```

Run `npm run build`. Astro will generate the post URL from the folder and filename,
and the shared post layout will render the Markdown body.
